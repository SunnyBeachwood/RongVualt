# RongVault 更新说明

## 1.4.1 — 2026-09-13

### 新增

- 首页主题与内置文件管理器同步，支持手动主题色、动态配色、Material 3、夜间模式和纯黑模式。
- 容器导航项显示容量信息，并使用解锁状态图标。
- 内置文件管理器支持“另存为”文档提供者流程。
- 新增“离开应用后需要身份验证”设置，默认开启，可在内置文件管理器的“设置 → 行为”中关闭。
- README 增加外部项目、库、版本和许可证来源索引。

### 修复与界面调整

- 修复新窗口入口无效的问题。
- 改善夜间模式双栏中间分割线的阴影和可辨识度。
- 将设置中的 “File name lines” 本地化为中文。
- 重新排列解密界面的浏览、导入/导出、锁定和返回操作。
- 修复文件管理器退到后台后，认证成功仍停留在首页的问题；现在会恢复原文件管理器页面。
- 修复 `ManagedVolumeSession` 单元测试与当前构造函数签名不一致的问题。

### 验证

- 正式版构建：`assembleLiteRelease` 通过。
- 单元测试：`testLiteDebugUnitTest` 通过。
- 已在无线 ADB 设备 `192.168.1.23:5555` 上安装并启动 `app.rongvault` 进行基础调试。

### 已知限制

- 当前仍只提供 `arm64-v8a` 正式包。
- 部分 VeraCrypt 算法/KDF、Root、FTP、压缩包和 SAF 组合仍需持续进行设备与互操作验证。
- 本项目不是 VeraCrypt 官方客户端，也未经过独立密码学或安全审计。
